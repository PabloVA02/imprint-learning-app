# Imprint Learning App

A mobile-first visual learning application built with React and TypeScript.
It combines short educational lessons, visual book summaries, discovery,
saved content, profile progress and an AI assistant.

The project also includes a complete 18-screen onboarding and trial flow.
Every screen is made from real interface components rather than full-screen
captures. It includes animated illustrations, selectable preferences and plans,
progress navigation, swipe gestures, keyboard support, loading feedback and
reduced-motion support.

## Main features

- Reader-style educational Shorts
- Visual book library and book detail pages
- Animated visual summaries
- Discover and saved-content sections
- Profile and learning progress
- Ask-AI interface
- Responsive mobile presentation
- Automated interface tests

## Run

```bash
npm install
npm run dev
```
